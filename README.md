# 🍕 Pizza Sales Dashboard | Power BI

## 📌 Overview

An interactive **Pizza Sales Dashboard** built in **Power BI** to analyze sales performance, customer ordering patterns, product trends, and revenue distribution. The dashboard enables stakeholders to monitor KPIs and uncover actionable business insights.

---

## ✨ Features

* 📊 Interactive slicers for **Pizza Size** and **Category**
* 💰 KPI cards for Revenue, Orders, Pizzas Sold, and Average Order Value
* ⏰ Sales analysis by Hour, Day, and Time of Day
* 🍕 Top 10 Best-Selling Pizzas visualization
* 💵 Top 10 Revenue-Generating Pizzas analysis
* 📈 Revenue distribution across pizza categories
* 🔍 Dynamic filtering for deeper business insights

---

## 🛠️ Tools Used

* Power BI
* Power Query
* DAX
* Excel/CSV Dataset

## 📈 Key Insights

* 💰 Total Revenue: **$817.86K**
* 🛒 Total Orders: **21K**
* 🍕 Total Pizzas Sold: **50K**
* ⭐ Classic category generated the highest revenue share.
* 📅 Friday recorded the highest order volume.
* ⏰ Peak sales occurred during lunch and evening hours.
* 🍕 Identified the top-selling and highest-revenue pizzas.

## 🚀 Project Objective

 To transform raw pizza sales data into an interactive BI dashboard that helps businesses track performance, understand customer behavior, and make data-driven decisions.
